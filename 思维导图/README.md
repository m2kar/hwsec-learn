# 硬件安全知识思维导图

以 YAML 存储的硬件安全知识概念导图，用于系统学习领域知识。根节点为**硬件安全**，从根到叶概念逐层变小（领域 → 子领域 → 概念 → 具体术语）。

- 数据文件：[硬件安全知识思维导图.yaml](./硬件安全知识思维导图.yaml)（v1.0，610 个节点）
- 可交互网页：[硬件安全知识思维导图.html](./硬件安全知识思维导图.html)（markmap 渲染，资源已离线内联，双击即可打开；初始展开到第 2 层，点击节点圆点逐层展开，工具栏支持缩放/适配/递归展开/暗色切换）
- Xmind 导入版：[硬件安全知识思维导图-xmind.md](./硬件安全知识思维导图-xmind.md)（纯嵌套列表，`tag` 标签用【】、`desc` 解释用冒号内联进主题文本，610 行与 YAML 节点一一对应）
- Markdown 大纲：[硬件安全知识思维导图.md](./硬件安全知识思维导图.md)（markmap 渲染用中间产物）
- 依据：《硬件安全学习讲义》13 章 + 考试知识覆盖面 + 2025-2026 公开资料调研补充

## 结构约定

```yaml
root:
  name: 概念名        # 必填
  desc: 一句话解释     # 便于学习，可省略
  tag: 标注           # 高频考点 / 考纲重点 / 国密 / 已破 / 拓展(考试不考) / 2026前沿
  children: [...]     # 子概念
```

## 使用方法

**1. 直接阅读**：YAML 缩进即层级，`tag` 字段标出考纲重点与高频考点。

**2. 一键重建全部产物**（YAML 改动后执行）：

```bash
python3 build.py
```

自动完成 YAML → Markdown 大纲 → markmap 离线 HTML → Xmind 导入版 Markdown 四步，并给 HTML 打上交互补丁（中文标题、初始展开到第 2 层、加载后自动适配视图）。

**3. 导入 Xmind**：打开 Xmind → 文件 → 导入 → Markdown，选择 `硬件安全知识思维导图-xmind.md`。该文件为纯嵌套列表格式（单根、2 空格缩进），标签与解释已内联进主题文本，导入后与 YAML 节点一一对应、无信息丢失。幕布、思维导图类工具的 Markdown 导入同理。

**3. 导入 XMind / 幕布等**：先按上法转成 Markdown 缩进大纲，再导入。

## 维护

讲义章节更新或考纲变化时，修改 YAML 后运行 `python3 build.py` 重建 Markdown 与 HTML；`2026前沿` 标签的节点（如 TROPIC01 激光注入、MilanLaunchy、GPUBreach、中断注入绕过 Spectre v2）来自 2025-2026 公开报道，考试不作为重点、仅供理解趋势。
