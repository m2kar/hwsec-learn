# 硬件安全学习中心

硬件安全知识讲义与在线刷题的单文件静态站点：**11 章系统讲义 + 300 道自测题（含解析）**。

**在线使用**：<https://m2kar.cn/hwsec-learn/>

| 路径 | 内容 |
|------|------|
| `/`（index.html） | 门户首页 |
| `/lecture/` | 硬件安全学习讲义（11 章，含术语速查表与参考资料） |
| `/quiz/` | 在线刷题：顺序 / 随机 / 错题重刷、按知识域与难度筛选、模拟计分（单选 2 分、多选 3 分）、错题本本地保存 |
| `硬件安全题库2.csv` | 完整题库（15 列：题号 / 题型 / 知识域 / 难度 / 题干 / 选项 A–G / 答案 / 解析 / 考点） |

## 更新

- 题库：修改 `硬件安全题库2.csv` 后运行 `python3 build_quiz.py` 重新生成 `quiz/index.html`。网页支持在多个内嵌题库之间切换，错题本和刷题记录按题库分别保存。
- 多题库构建示例：`python3 build_quiz.py --bank '硬件安全题库2=硬件安全题库2.csv' --bank '专项练习=专项练习.csv'`。每个 CSV 都应使用相同的表头；网页不会在浏览器端读取本地 CSV。
- 讲义：讲义源文件（Typst）独立维护，导出 HTML 后放入 `lecture/` 目录。

## 内容范围

密码算法与后量子密码、同态加密与隐私计算、侧信道与故障注入、硬件可信根与安全启动、TPM/HSM/TEE 与机密计算、处理器微架构安全、供应链安全、调试接口与底层软件安全、安全测评与标准认证。

> 内容仅供学习交流使用。
