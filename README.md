# 硬件安全刷题

单文件网页刷题应用，内置 126 道硬件安全题目（82 单选 + 44 多选），每题附解析与考点标签。

**在线使用**：<https://m2kar.github.io/hwsec-quiz/>

## 功能

- 顺序 / 随机 / 错题重刷三种模式
- 按 18 个知识域、题型（单选/多选）、难度筛选
- 模拟计分：单选 2 分、多选 3 分（多选需完全选对才得分）
- 错题本自动记录（浏览器本地存储，刷新不丢失）

## 题库

题目数据在 `硬件安全题库.csv`（UTF-8 编码，12 列：题号 / 题型 / 知识域 / 难度 / 题干 / 选项 / 答案 / 解析 / 考点），可单独下载用于自制刷题工具。

## 更新题库

修改 CSV 后运行 `python3 build_quiz.py` 重新生成 `index.html`，提交推送即可。
