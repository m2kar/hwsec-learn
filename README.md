# 硬件安全学习中心

硬件安全知识讲义与在线刷题的静态站点：**11 章系统讲义 + 622 道自测题（含解析，两个题库）**。

**在线使用**：<https://m2kar.cn/hwsec-learn/>

| 路径 | 内容 |
|------|------|
| `/`（index.html） | 门户首页 |
| `/lecture/` | 硬件安全学习讲义（11 章，含术语速查表与参考资料） |
| `/quiz/` | 在线刷题：顺序 / 随机 / 错题重刷、按知识域与层级筛选、模拟计分（单选 2 分、多选 3 分）、错题本本地保存 |
| `硬件安全题库2.csv` | 主题库（622 题 = 核心 212 + 扩展 410，15 列：题号 / 题型 / 知识域 / 难度 / 题干 / 选项 A–G / 答案 / 解析 / 考点） |
| `硬件安全题库.csv` | 旧题库（126 题，12 列：选项仅 A–D） |

## 题库 2 的构成（2026-09 全新编写）

- **9 大知识域**：密码算法 117 · 侧信道攻击 95 · 故障注入 78 · 硬件可信根 94 · TEE 74 · 处理器微架构 54 · 供应链安全 54 · 调试接口安全 48 · 综合 8
- **两个层级**：核心 212 题（Z001–Z212，覆盖考纲主干概念）+ 扩展 410 题（Y001–Y410，工程细节 / 案例复盘 / 行业标准 / 华为实践与综合体系）
- **题型**：单选 334（5 选项）、多选 288（6 选项，正确项 2–4 个）
- **命题原则**：场景化题干；干扰项取自真实误区与相邻概念（无凑数项）；避免语气/长度泄露答案；答案字母分布均衡；解析逐项说明排除依据
- 题目由”子代理拟候选 + 逐题推敲定稿”产出；2026-09-27 对照考纲做覆盖缺口分析后补录 22 题（Z201–Z212、Y401–Y410：EMFI 机理/防护/平台、功耗与电磁对比、NIST PQC 定稿标准、TPM 防字典攻击、BMC 带外管理、ARM CCA），并修复 Y057 多选正确项超限问题

## 更新

- 题库：`quiz/index.html` 打开时自动读取根目录的题库 CSV 并解析渲染，改完 CSV 刷新页面即生效，无需重新构建。需通过 HTTP 访问（如在本目录运行 `python3 -m http.server 8000` 后打开 `/quiz/`）；直接双击（file://）会被浏览器拦截，页面会给出启动本地服务的提示。错题本和刷题记录按题库分别保存。
- 选项乱序：作答时选项随机排列，提交后显示原始字母标注，解析中的字母引用与原始字母对应。
- 新增题库：在 `quiz/index.html` 的 `BANK_SOURCES` 列表中加一行 `{ name: "名称", file: "../文件.csv" }`，各 CSV 使用相同表头。
- 讲义：讲义源文件（Typst）独立维护，导出 HTML 后放入 `lecture/` 目录。
