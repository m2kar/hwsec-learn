# 硬件安全学习中心

硬件安全知识讲义与在线刷题的静态站点：**11 章系统讲义 + 346 道自测题（含解析，两个题库）**。

**在线使用**：<https://m2kar.cn/hwsec-learn/>

| 路径 | 内容 |
|------|------|
| `/`（index.html） | 门户首页 |
| `/lecture/` | 硬件安全学习讲义（11 章，含术语速查表与参考资料） |
| `/quiz/` | 在线刷题：顺序 / 随机 / 错题重刷、按知识域与难度筛选、模拟计分（单选 2 分、多选 3 分）、错题本本地保存 |
| `硬件安全题库2.csv` | 题库（220 题，15 列：题号 / 题型 / 知识域 / 难度 / 题干 / 选项 A–G / 答案 / 解析 / 考点） |
| `硬件安全题库.csv` | 题库（126 题，12 列：选项仅 A–D，其余同上） |

## 更新

- 题库：`quiz/index.html` 打开时自动读取根目录的题库 CSV 并解析渲染，改完 CSV 刷新页面即生效，无需重新构建。需通过 HTTP 访问（如在本目录运行 `python3 -m http.server 8000` 后打开 `/quiz/`）；直接双击（file://）会被浏览器拦截，页面会给出启动本地服务的提示。错题本和刷题记录按题库分别保存。
- 新增题库：在 `quiz/index.html` 的 `BANK_SOURCES` 列表中加一行 `{ name: "名称", file: "../文件.csv" }`，各 CSV 使用相同表头。
- 讲义：讲义源文件（Typst）独立维护，导出 HTML 后放入 `lecture/` 目录。

## 内容范围

密码算法与后量子密码、同态加密与隐私计算、侧信道与故障注入、硬件可信根与安全启动、TPM/HSM/TEE 与机密计算、处理器微架构安全、供应链安全、调试接口与底层软件安全、安全测评与标准认证。

> 内容仅供学习交流使用。
